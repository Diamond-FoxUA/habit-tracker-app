# Habit Tracker App

A functional, reactive habit tracking application built to help users manage daily goals, track streaks, and visualize progress. This project focuses on modern React development patterns and clean code architecture.

---

## 🚀 Features
- **Add & Delete Habits:** Dynamically manage your list of daily goals.
- **Toggle Completions:** Track habits across different dates with persistent storage.
- **Interactive UI:** Real-time feedback and responsive design using Tailwind CSS.
- **Date Navigation:** Navigate between weeks to view historical data.

---

## 🛠️ Built With
- React (with TypeScript)
- Vite (for fast build and development)
- Tailwind CSS (for styling)
- date-fns (for date manipulation)

---

## ⚙️ Getting Started
**Prerequisites**
Make sure you have Node.js and npm installed on your machine.

**Installation**

- Clone the repository: ```git clone```
- Install dependencies: ```npm install```
- Start the development server: ```npm run dev```

---

## 🧠 Key Concepts Applied
- **Component-Based Architecture:** Breaking down the UI into reusable functional components.
- **State Management:** Using useState and useContext for global and local application state.
- **Custom Hooks:** Abstracting logic like useLocalStorage and context hooks for cleaner code.
- **Effect Handling:** Managing side effects with useEffect.
